Politique de confidentialité

TaskyMate — ce que TaskyMate fait de vos données

Engagement de confidentialité

TaskyMate collecte uniquement les données nécessaires au fonctionnement de l'application. Aucune donnée n'est vendue ni utilisée à des fins publicitaires.

Éditeur et responsable du traitement : Adam Saaidy. Contact : pro.saaidy@gmail.com.

1. Données collectées

Données du parent

  • Adresse e-mail (pour la connexion)
  • Mot de passe et code PIN parent (empreintes bcrypt, jamais en clair)
  • Sessions de connexion : dates et type d'appareil ou de navigateur, pour la liste des appareils connectés
  • Essai gratuit et consentements donnés pour chaque enfant

Données de l'enfant

  • Prénom
  • Mois et année de naissance
  • Code PIN
  • Tâches, routines et planning
  • Progression, expérience (XP) et compagnon
  • Coffres, inventaire, Taskis et boutique
  • Arène et expéditions
  • Énigmes et citations
  • Petits mots du parent
  • Réponses au questionnaire d'aventure
  • Notifications liées au profil enfant
  • Données de consentement

Le code PIN de l'enfant est stocké sous forme d'empreinte bcrypt, jamais en clair.

Données techniques

  • Journaux du serveur : événements de fonctionnement et erreurs, sans mot de passe, code PIN ni jeton de connexion, et avec les adresses e-mail masquées
  • TaskyMate n'enregistre pas votre adresse IP

2. Utilisation et partage

Vos données servent à

  • Faire fonctionner le service : compte, tâches, progression, compagnon et activités
  • Authentifier les comptes et protéger leur accès
  • Répondre à vos demandes et corriger les problèmes pendant la phase de test

Partage

  • Aucune donnée n'est vendue.
  • Aucune donnée n'est utilisée à des fins publicitaires.
  • Certains prestataires techniques nécessaires au fonctionnement du service (par exemple l'hébergement du serveur ou la distribution de l'application) peuvent traiter des données, uniquement pour faire fonctionner TaskyMate.

3. Sous-traitants techniques

Pendant la phase de test, ces prestataires peuvent traiter des données, uniquement pour faire fonctionner TaskyMate :

  • Hébergement et serveur : le serveur et la base de données de TaskyMate, qui conservent les comptes, les profils et la progression.
  • Cloudflare : tunnel sécurisé (HTTPS) qui achemine les échanges entre l'application et le serveur pendant la phase de test.
  • Apple TestFlight : distribution des versions de test sur iPhone et iPad.
  • Firebase App Distribution (Google) : distribution des versions de test sur Android.
  • RevenueCat : gestion des achats intégrés, uniquement lorsque les achats seront activés. Aucun achat n'est actif aujourd'hui.

4. Sécurité des données

  • Les échanges entre l'application et le serveur passent par HTTPS.
  • Les mots de passe et les codes PIN sont stockés sous forme d'empreintes bcrypt, non réversibles, jamais en clair.
  • L'espace parent est protégé par le code PIN parent ; l'espace de l'enfant par son code PIN.

Nous nous efforçons de protéger vos données selon les bonnes pratiques de sécurité ; aucun système n'est cependant infaillible.

5. Stockage sur l'appareil

L'application garde sur l'appareil, dans son stockage local

  • La session de connexion
  • La dernière adresse e-mail de connexion, pour la préremplir (jamais le mot de passe)
  • Des préférences d'affichage et l'état de certains écrans

TaskyMate n'utilise aucun cookie, aucun traceur publicitaire et aucun outil de mesure d'audience. Se déconnecter efface ce stockage, sauf la dernière adresse de connexion.

6. Conservation et suppression

Durée de conservation :

  • Données du compte et des enfants : tant que le compte existe
  • Petits mots du parent à l'enfant : tant que le compte de l'enfant existe (seuls les 30 derniers jours sont affichés ; un mot encore non lu peut être retiré)
  • Journaux du serveur : le temps nécessaire au diagnostic et à la sécurité pendant la phase de test

Suppression du compte : la suppression du compte, depuis les réglages parent, efface immédiatement les données actives du compte et des profils enfants. Pendant la phase de test, des sauvegardes ou journaux techniques peuvent encore contenir certaines de ces données pendant un temps limité, jusqu'à leur renouvellement.

Retrait du consentement : le consentement peut être retiré à tout moment depuis les réglages parent. Le retrait efface les données de l'enfant ; seul son prénom est conservé, avec la mention du retrait. Le profil peut ensuite être supprimé définitivement.

7. Bases légales et droits RGPD

Bases légales

  • Données du parent : exécution du contrat, c'est-à-dire la fourniture du service
  • Données de l'enfant : consentement du parent

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : consulter vos données personnelles et celles de votre enfant
  • Droit de rectification : corriger ou mettre à jour vos informations
  • Droit à l'effacement : supprimer vos données et celles de votre enfant
  • Droit à la portabilité : récupérer vos données dans un format lisible, sur demande par e-mail
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit de retrait du consentement : retirer votre consentement pour les données de votre enfant, depuis les réglages parent

Pour exercer vos droits : écrivez à pro.saaidy@gmail.com. Nous répondons dans les meilleurs délais et dans les délais légaux applicables.

8. Phase de test

  • TaskyMate est actuellement en phase de test.
  • Le service peut être interrompu, modifié ou réinitialisé à tout moment.
  • Aucune disponibilité continue n'est garantie.
  • Certaines données de test peuvent être perdues.
  • Pendant cette phase de test, TaskyMate est gratuit.
  • Aucun achat en argent réel n'est disponible dans cette version.
  • La durée d'essai affichée dans l'application peut être prolongée ou adaptée pendant la phase de test.
